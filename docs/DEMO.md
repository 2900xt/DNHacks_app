# Demo

The judged artifact is a **2–5 minute demo**, not this repo. Judges will never read
the code and have no idea what happened during the 26 hours.

**If you want them to know it, it must be in the demo.**

The authoritative demo script lives in the brain repo:
[`../../dnhacks26-brain/strategy/DEMO_PATH.md`](../../dnhacks26-brain/strategy/DEMO_PATH.md).

This file is the *operational* side: how to actually make the demo run.

## Pre-demo checklist

- [ ] `make demo` works from a clean clone on the demo laptop
- [ ] Runs with **wifi off** (hotspot or fully local)
- [ ] Hardware powered, enumerated, and re-seated once to prove it recovers
- [ ] Fallback path rehearsed (replay data, pre-computed results)
- [ ] Laptop: notifications off, screen sleep off, battery charged, brightness up
- [ ] Browser zoomed so the back row can read it
- [ ] Demo video recorded and uploaded **before** the last feature is finished

## Recording

Start the demo video with **2–3 hours left**, not at the end. It is almost always a
better use of the final hours than one more feature.
